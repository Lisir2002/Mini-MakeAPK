# Concept C — 混合路径（目标架构）

**描述**：设备端 WebView 即时封装用于**即时预览与轻量出包**（Concept A）；对 Vue/PHP/进阶需求走**云端真构建**（Concept B）产出正式签名 APK。同一可爱 UI 壳，两种构建后端按输入类型自动路由。

- **Pros**：兼顾"快演示"与"真能力"；用户体验一致；随后端成熟平滑升级。
- **Cons**：两套构建路径，架构与状态管理更复杂；需清晰的路由与加载态。
- **预计工作量**：A（中）+ B（高），分阶段。
- **团队目标架构**：sprint-1 = A + B 的契约设计；后续 sprint 落地 B。
