# Release 标题概括表

> 本文件是 Release 标题「— 概括」段的唯一来源，由 `.github/workflows/release.yml`
> 在创建 Release 时读取拼接（格式规约见 [`docs/RELEASE_NOTES.md`](../RELEASE_NOTES.md) §2）。
> 每行一条：`版本号|概括`。概括 ≤20 字、用户语言、描述本次最核心的 1～2 个变化，禁止内部术语。
> 发版时必须为本版本新增一行，漏写时 CI 会 warning 并产出不带概括段的标题。
