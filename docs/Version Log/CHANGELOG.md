# Changelog

本文件记录 MMA 的用户可见变更，采用**用户面向格式**（规约见 [`docs/RELEASE_NOTES.md`](../RELEASE_NOTES.md)）。

> **2026-10-25 格式变更**：本日志由工程面向改为**用户面向唯一格式**。
> 结构：版本标题 → 100 字简介 → 新功能 → 改进 → 移除 → 修复 → 安全 → 已知问题；
> 条目格式 `**4-9 字小标题**：20-40 字说明`；禁止 emoji；仅记录用户可感知的应用程序变更。
> **2026-10-25 版本合并**：内部首发版 `v0.0.0.0+1`（成品未对外分发）的日志已并入
> `[0.0.0.1-rc1]`，其独立条目与 Release 页面已撤并；git tag 保留作史实。

- 最新版本置顶，倒序排列。
- 日期用 ISO 8601（`YYYY-MM-DD`）。
- **破坏性变更用「注意」显著标注并说明用户需要做什么。**
- **禁止使用 emoji**：分类标题和正文保持纯文字，简洁专业。
- 版本号规则见 [`docs/VERSIONING.md`](../VERSIONING.md)：纯四段式，正式版需用户授权、否则发 RC。

## [0.0.0.1-rc10] - 2026-10-29

> 内置浏览器告别白屏：混合内容不再被拦截，加载失败有提示，HTML 项目可直接预览。应用图标支持上传自己的图片，进阶设置新增加载进度条可选上下位置，编辑页留白与下拉样式更精致。

### 新功能

- **加载进度条**：进阶设置新增网页加载进度条，支持开关并可选顶部或底部显示位置。

### 改进

- **图标上传**：应用图标支持从相册上传自己的图片，自动居中裁方并垫上主题色。
- **留白收敛**：编辑页各配置卡片改为随内容自适应高度，底部不再有大片空白。
- **入口一处维护**：项目代码页不再重复显示入口选择，入口文件统一在基本信息卡设置。
- **下拉更清晰**：缓存模式下拉列表加描边并提亮容器底色，选中项更好认。

### 修复

- **白屏修复**：内置浏览器放行混合内容并接管进度与报错，多数网站不再打开即空白。
- **代码可预览**：自己写的 HTML 项目现在能直接进入预览，不再提示仅支持网址。
- **失败有提示**：网页加载失败时显示可见提示，不再静默白屏无从判断。

### 移除

- **形状预览**：应用图标的圆形方形预览已移除，点击图标即可直接上传自定义图片。

### 已知问题

- **暂无已知问题**：本轮更新后未发现影响正常使用的已知问题，可放心升级体验。

## [0.0.0.1-rc9] - 2026-10-29

> 项目文件搬进手机里的 MMA 文件夹：删掉了也不怕，重新打开应用会自动从数据库补全；「我的」新增运行日志页，问题、操作、诊断、安全四类分级一目了然；新建项目的类型选择卡片焕新，应用图标支持自定义裁切与底色，启动图标上的 MiniMe-MMA 名字也回来了。

### 新功能

- **项目文件落地**：创建项目时同步生成外部项目目录，配置、源码与图标文件管理器里直接可看。
- **目录自动补全**：外部项目目录被删除后，重新打开应用会自动从数据库拉取补全，日志目录同理。
- **运行日志页**：「我的」新增运行日志入口，按问题、行为、诊断、安全四组分区，可筛选。
- **图标形状预览**：选择应用图标后，可预览圆形、方圆、圆角方三种启动器遮罩下的效果。
- **图标自动垫底**：选择透明底图片作为应用图标时，自动垫上项目主题色，避免在启动器上显示成黑块。

### 改进

- **类型选择焕新**：类型卡片升级为图标徽标加一句话描述，底部新增可点击指示条与触感反馈。
- **启动图标补名**：主程序启动图标恢复 MiniMe-MMA 名称字标，圆形遮罩下完整可见。
- **保存提示气泡**：保存成功后留在当前页，顶栏正中浮出气泡提示，三秒自动消失，点击立即关闭。
- **入口地址可改**：编辑项目时可直接修改网址或网页入口，不必删掉重建项目。
- **顶栏回入口**：外壳顶栏新增回入口按钮，切到其他标签页后一键回到首页。
- **保存不再跳页**：保存成功后停留在编辑页，可继续调整或直接预览。
- **下拉更精致**：下拉列表选中项换成第三强调色并加上柔和投影。

### 修复

- **图标不再切名**：修复启动图标把象征性应用名称裁切掉的问题，名称行完整保留。

### 已知问题

- **源码包入口暂锁**：源码包类项目的入口暂不支持在编辑页更换，可新建项目解决。

## [0.0.0.1-rc8] - 2026-10-29

> 进阶配置从能填变成好用：条目可隐藏、删除前先确认、填写有误不让保存；下拉列表与弹窗等界面控件重新绘制，更精致；预览页只呈现项目真实配置，与导出结果完全一致。

### 新功能

- **删除前先确认**：删除顶栏底栏条目时会先弹出确认，误点一下不再直接丢掉配置。
- **条目可单独隐藏**：每个条目都能单独开关显示或隐藏，不用删掉也能临时不显示。
- **排序编辑更顺手**：条目支持上移下移与单独编辑，操作图标分区排布，误触更少。

### 改进

- **弹窗更精致**：确认与输入弹窗重新绘制，边角更圆润，开关与按钮的动效更自然。
- **下拉列表更好选**：缓存模式等下拉列表改为分段样式，选中项一目了然，不再抖动。
- **数值调节不跳变**：条目数量与抽屉宽度改为加减调节，到上下限时按钮直接置灰。
- **保存前先校验**：条目标题与地址填写不合规时无法保存，避免生成打不开的配置。
- **架构细节优化**：应用架构细节优化，提高产品质量，优化用户体验。

### 移除

- **预览页不再切壳**：预览页不再提供切换外壳的入口，预览即为项目真实配置。

### 修复

- **预览与导出一致**：未配置外壳的项目，预览不再显示默认样式，与导出结果保持一致。
- **切换项目不乱选**：切换项目后不会残留上一项目的选中项，界面状态正确重置。

### 已知问题

- **暂无已知问题**：本轮更新后未发现影响正常使用的已知问题，可放心升级体验。

## [0.0.0.1-rc7] - 2026-10-28

- **项目卡片更清晰**：新建页的图标与说明排版重新梳理，层级更清楚。

### 修复

- **预览不再跳出浏览器**：网页内点击链接或跳转时留在应用内打开，顶栏底栏保持可用。
- **图标不再被裁切**：修正启动图标的显示范围，圆形与方形图标都完整显示，不再缺边。
- **统一默认配色**：新建项目的默认主题色与色板统一为新配色，不再出现旧的粉色。

### 已知问题

## [0.0.0.1-rc2] - 2026-10-26

界面焕然一新：项目、开发中与我的三个栏目经底栏一键直达，间距更紧凑、按压有回弹；首次启动自动建立 MMAFile 本地目录，运行日志实时可查，退出与取消的记录不再丢失。

### 新功能

- **本地文件目录**：首次启动即建立 MMAFile 本地目录，安装包、日志、项目、设置与备份各归其位。
- **统一界面骨架**：所有页面统一顶部标题栏与底部导航，视觉风格一致不跳变。
- **底栏快速切换**：项目、开发中与我的三个栏目可通过底部导航一键互达，不用逐页返回。
- **项目工作台**：输入网址与项目列表合并在同一页，新建项目不用来回翻页。
- **开发中预告**：新功能在建状态与路线图一目了然，不再面对空白页面。
- **个人中心**：我的页面集中展示版本信息与存储状态，设置、关于、仓库与升级入口清晰可达。
- **开源仓库直达**：在「我的」页面一键跳转 GitHub 仓库，源码与说明随手可查。

### 改进

- **界面更紧凑**：全局间距温和收紧，同屏信息更多，页面观感更精致。
- **日志实时可见**：授权存储后运行日志即写入 MMAFile/Log，随时可查；暂不授权下次启动再问。
- **按压回弹动效**：按钮按下时轻微收缩再回弹，触感更柔和有趣。
- **暗色对比优化**：暗色主题下提示与状态色对比度提升，夜间阅读更清晰。
- **磨砂栏就打底**：顶栏与底栏具备半透明磨砂能力，为后续自定义主题铺路（当前默认关闭）。

### 修复

- **退出记录更完整**：修复崩溃或退出瞬间，已产生但尚未落盘的运行记录可能丢失的问题。
- **取消更加可靠**：取消构建后不再意外记为成功，历史中标记为已取消。
