# Changelog

本文件记录 MMA 的用户可见变更，采用**用户面向格式**（规约见 [`docs/RELEASE_NOTES.md`](../RELEASE_NOTES.md)）。

> **2026-10-25 格式变更**：本日志由工程面向改为**用户面向唯一格式**。
> 结构：版本标题 → 100 字简介 → 新功能 → 改进 → 移除 → 修复 → 安全 → 已知问题；
> 条目格式 `**4-9 字小标题**：20-40 字说明`；禁止 emoji；仅记录用户可感知的应用程序变更。
> **2026-10-25 版本合并**：内部首发版 `v0.0.0.0+1`（成品未对外分发）的日志已并入
> `[0.0.0.1-rc1]`，其独立条目与 Release 页面已撤并；git tag 保留作史实。

- 最新版本置顶，倒序排列。
- 日期用 ISO 8601（`YYYY-MM-DD`）。
- **破坏性变更用「注意」显著标注并说明用户需要做什么。**
- **禁止使用 emoji**：分类标题和正文保持纯文字，简洁专业。
- 版本号规则见 [`docs/VERSIONING.md`](../VERSIONING.md)：纯四段式，正式版需用户授权、否则发 RC。

## [0.0.0.1-rc5] - 2026-10-28

> 新增可配置的应用外壳：你可以为项目自定义顶栏、顶部分页、底栏与侧边抽屉，并在应用内实时预览效果，确认无误后即可导出为独立可安装的应用。

### 新功能

- **自定义应用外壳**：为项目配置顶栏、顶部分页、底栏与侧边栏，外观完全由你决定。
- **外壳实时预览**：编辑外壳的同时在应用内实时预览效果，所见即所得。
- **分页左右滑动**：顶部分类支持左右滑动切换，浏览内容更顺手。
- **侧边抽屉菜单**：新增原生侧边抽屉，常用入口统一收纳其中。
- **导出独立应用**：将配置好的外壳导出为独立可安装的应用，方便分发使用。

### 改进

- **项目内核升级**：项目的数据组织方式优化，创建与管理更加顺畅。

### 移除

- **旧版构建流程**：原有的本地构建与历史记录功能已移除，统一由外壳导出能力替代。

### 已知问题

- **暂无已知问题**：本轮更新后未发现影响正常使用的已知问题。

## [0.0.0.1-rc1] - 2026-10-25

MMA 首个公开发布：输入网址或 HTML 即可在设备端一键封装应用，构建历史本地加密保存；界面图标已重绘为矢量图形并支持读屏朗读，安装包更加轻量。

### 新功能

- **一键封装应用**：输入网址或 HTML 字符串，即可在设备端直接封装为可安装的应用。
- **本地即时预览**：封装前可先在应用内预览页面效果，确认无误后再生成安装包。
- **亮暗双主题**：界面自动跟随系统深浅色，基于感知均匀色板，久看舒适。
- **历史记录管理**：构建记录在本地加密保存，可随时回看、删除，数据不出设备。
- **构建过程反馈**：构建中显示进度动画，成功与失败均有明确的结果页面。

### 改进

- **图标矢量重绘**：返回、历史等界面图标改为矢量图形，任何屏幕尺寸下显示都清晰。
- **启动图标更新**：应用图标改用自适应矢量图形，新系统上呈现更精致的形状。
- **状态图标可读屏**：构建成功与失败页的状态图标补充朗读描述，视障用户可感知构建结果。
- **安装包瘦身**：安装包体积已缩减至 25MB 左右，下载与安装速度明显加快。

### 已知问题

- **暂无已知问题**：本轮更新后未发现影响正常使用的已知问题，真机验证结果将随后续版本补充。

## [0.0.0.1-rc2] - 2026-10-26

界面焕然一新：项目、开发中与我的三个栏目经底栏一键直达，间距更紧凑、按压有回弹；首次启动自动建立 MMAFile 本地目录，运行日志实时可查，退出与取消的记录不再丢失。

### 新功能

- **本地文件目录**：首次启动即建立 MMAFile 本地目录，安装包、日志、项目、设置与备份各归其位。
- **统一界面骨架**：所有页面统一顶部标题栏与底部导航，视觉风格一致不跳变。
- **底栏快速切换**：项目、开发中与我的三个栏目可通过底部导航一键互达，不用逐页返回。
- **项目工作台**：输入网址与项目列表合并在同一页，新建项目不用来回翻页。
- **开发中预告**：新功能在建状态与路线图一目了然，不再面对空白页面。
- **个人中心**：我的页面集中展示版本信息与存储状态，设置、关于、仓库与升级入口清晰可达。
- **开源仓库直达**：在「我的」页面一键跳转 GitHub 仓库，源码与说明随手可查。

### 改进

- **界面更紧凑**：全局间距温和收紧，同屏信息更多，页面观感更精致。
- **日志实时可见**：授权存储后运行日志即写入 MMAFile/Log，随时可查；暂不授权下次启动再问。
- **按压回弹动效**：按钮按下时轻微收缩再回弹，触感更柔和有趣。
- **暗色对比优化**：暗色主题下提示与状态色对比度提升，夜间阅读更清晰。
- **磨砂栏就打底**：顶栏与底栏具备半透明磨砂能力，为后续自定义主题铺路（当前默认关闭）。

### 修复

- **退出记录更完整**：修复崩溃或退出瞬间，已产生但尚未落盘的运行记录可能丢失的问题。
- **取消更加可靠**：取消构建后不再意外记为成功，历史中标记为已取消。
