# MMA 0.0.0.1-rc13 Version Log

> 项目代码页目录浏览升级为可复用卡片列表组件，并补全文件管理能力；内置浏览器完成白屏专项升级，白屏时能给出根因提示并可跳过缓存自愈重载。

### 新功能

- **目录浏览器组件**：独立可复用组件，支持文件与文件夹增删改，及复制剪切粘贴浏览。
- **空文件夹约定**：以 `name/` 空条目持久化空目录，旧数据天然兼容。

### 改进

- **卡片列表式浏览**：项目代码页由缩进树改为逐层卡片列表，按扩展名映射图标与底色。
- **文件管理**：新增文件夹、重命名、目录递归删除与复制 / 剪切粘贴（同名自动改名）。
- **白屏可诊断**：内置浏览器白屏时给出根因提示并可跳过缓存自愈重载。
- **保存即回列表**：新增项目保存成功后自动返回项目列表，不再提供页内即时预览。
