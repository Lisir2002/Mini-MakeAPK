# MMA 0.0.0.1-rc17 Version Log

> 内置浏览器按社区成熟开源实现重做加载处理：不再暴露内置浏览器标记、证书异常自动重试、加载失败给出可读错误页；运行日志的级别配色与详情排版同步修正。

### 新功能

- **原生错误页**：网页加载失败时在页面内直接显示原因与重试入口，不再只留一片空白。
- **证书自动降级**：少数站点证书配置异常时自动改用明文地址重试一次，多数情况可直接打开。

### 改进

- **浏览器身份归一**：访问网页时不再暴露内置浏览器标记，被站点降级或返回空页的情况明显减少。
- **首帧判定留痕**：日志开始记录页面真正画出的时刻，空白页可区分加载未完成与画面未绘制。
- **跳转链可见**：网页发生跳转时记录每一次地址变化，等待时间能归因到网络还是页面本身。

### 修复

- **缓存被误关**：修复自愈一次后缓存被长期关闭的问题，长时间使用不再越用越慢。
- **日志级别配色**：修复警告与信息同色、调试与信息难以区分的问题，日志级别一眼可辨。
- **详情排版层级**：修复日志详情标题与正文同字号、字段不对齐的问题，长内容阅读更清晰。
