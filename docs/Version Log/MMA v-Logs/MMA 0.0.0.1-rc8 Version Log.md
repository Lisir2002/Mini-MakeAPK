# MMA 0.0.0.1-rc8 Version Log

> 进阶配置从能填变成好用：条目可隐藏、删除前先确认、填写有误不让保存；下拉列表与弹窗等界面控件重新绘制，更精致；预览页只呈现项目真实配置，与导出结果完全一致。

### 新功能

- **删除前先确认**：删除顶栏底栏条目时会先弹出确认，误点一下不再直接丢掉配置。
- **条目可单独隐藏**：每个条目都能单独开关显示或隐藏，不用删掉也能临时不显示。
- **排序编辑更顺手**：条目支持上移下移与单独编辑，操作图标分区排布，误触更少。

### 改进

- **弹窗更精致**：确认与输入弹窗重新绘制，边角更圆润，开关与按钮的动效更自然。
- **下拉列表更好选**：缓存模式等下拉列表改为分段样式，选中项一目了然，不再抖动。
- **数值调节不跳变**：条目数量与抽屉宽度改为加减调节，到上下限时按钮直接置灰。
- **保存前先校验**：条目标题与地址填写不合规时无法保存，避免生成打不开的配置。
- **架构细节优化**：应用架构细节优化，提高产品质量，优化用户体验。

### 移除

- **预览页不再切壳**：预览页不再提供切换外壳的入口，预览即为项目真实配置。

### 修复

- **预览与导出一致**：未配置外壳的项目，预览不再显示默认样式，与导出结果保持一致。
- **切换项目不乱选**：切换项目后不会残留上一项目的选中项，界面状态正确重置。

### 已知问题

- **暂无已知问题**：本轮更新后未发现影响正常使用的已知问题，可放心升级体验。
