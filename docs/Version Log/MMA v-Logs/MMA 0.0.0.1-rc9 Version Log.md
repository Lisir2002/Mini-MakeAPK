# MMA 0.0.0.1-rc9 Version Log

> 保存项目后不再被弹回列表：顶栏正中会浮出提示气泡，三秒自动消失、点一下立即关闭；编辑项目时可以直接修改入口网址；外壳顶栏新增回入口按钮，逛到其他标签页也能一键回到首页；下拉列表与标签页体验同步打磨，观感更精致、来回切换更顺手。

### 新功能

- **保存提示气泡**：保存成功后留在当前页，顶栏正中浮出气泡提示，三秒自动消失。
- **入口地址可改**：编辑项目时可直接修改网址或网页入口，不必删掉重建项目。
- **顶栏回入口**：外壳顶栏新增回入口按钮，切到其他标签页后一键回到首页。

### 改进

- **保存不再跳页**：保存成功后停留在编辑页，可继续调整或直接预览，少一次来回。
- **点击立即关闭**：提示气泡支持点一下马上收起，不用等三秒自动消失。
- **下拉更精致**：下拉列表选中项换成第三强调色并加上柔和投影，观感更清晰。
- **标签页记忆**：每个标签页记住自己的浏览位置，来回切换不丢失当前页面。
- **重选即回首页**：再次点击当前标签页即可回到该页开头，操作更顺手。

### 已知问题

- **源码包入口暂锁**：源码包类项目的入口暂不支持在编辑页更换，可新建项目解决。
