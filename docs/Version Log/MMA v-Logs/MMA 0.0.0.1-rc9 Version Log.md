# MMA 0.0.0.1-rc9 Version Log

> 项目文件搬进手机里的 MMA 文件夹：删掉了也不怕，重新打开应用会自动从数据库补全；「我的」新增运行日志页，问题、操作、诊断、安全四类分级一目了然；新建项目的类型选择卡片焕新，应用图标支持自定义裁切与底色，启动图标上的 MiniMe-MMA 名字也回来了。

### 新功能

- **项目文件落地**：创建项目时同步在外部 Items 目录生成项目文件（配置快照、源码、图标副本），文件管理器里可直接查看。
- **目录自动补全**：外部项目目录被删除后，重新打开应用会自动从数据库拉取补全，日志目录同理。
- **运行日志页**：「我的」新增运行日志入口，按问题 / 行为 / 诊断 / 安全四组分区，支持按级别与分组筛选。
- **图标形状预览**：选择应用图标后，可预览圆形、方圆、圆角方三种启动器遮罩下的效果。
- **图标自动垫底**：选择透明底图片作为应用图标时，自动垫上项目主题色，避免在启动器上显示成黑块。

### 改进

- **类型选择焕新**：新建项目的类型卡片升级为图标徽标加一句话描述，底部新增可点击的位置指示条，滑动停稳有触感反馈。
- **启动图标补名**：主程序启动图标恢复 MiniMe-MMA 名称字标，圆形遮罩下完整可见。
- **保存提示气泡**：保存成功后留在当前页，顶栏正中浮出气泡提示，三秒自动消失，点击立即关闭。
- **入口地址可改**：编辑项目时可直接修改网址或网页入口，不必删掉重建项目。
- **顶栏回入口**：外壳顶栏新增回入口按钮，切到其他标签页后一键回到首页。
- **保存不再跳页**：保存成功后停留在编辑页，可继续调整或直接预览。
- **下拉更精致**：下拉列表选中项换成第三强调色并加上柔和投影。

### 修复

- **图标不再切名**：修复启动图标把象征性应用名称裁切掉的问题，名称行完整保留。

### 已知问题

- **源码包入口暂锁**：源码包类项目的入口暂不支持在编辑页更换，可新建项目解决。
