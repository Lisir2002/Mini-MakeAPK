# MMA 0.0.0.1-rc2 Version Log

界面焕然一新：项目、开发中与我的三个栏目经底栏一键直达，间距更紧凑、按压有回弹；首次启动自动建立 MMAFile 本地目录，运行日志实时可查，退出与取消的记录不再丢失。

## 新功能

- **本地文件目录**：首次启动即建立 MMAFile 本地目录，安装包、日志、项目、设置与备份各归其位。
- **统一界面骨架**：所有页面统一顶部标题栏与底部导航，视觉风格一致不跳变。
- **底栏快速切换**：项目、开发中与我的三个栏目可通过底部导航一键互达，不用逐页返回。
- **项目工作台**：输入网址与项目列表合并在同一页，新建项目不用来回翻页。
- **开发中预告**：新功能在建状态与路线图一目了然，不再面对空白页面。
- **个人中心**：我的页面集中展示版本信息与存储状态，设置、关于、仓库与升级入口清晰可达。
- **开源仓库直达**：在「我的」页面一键跳转 GitHub 仓库，源码与说明随手可查。

## 改进

- **界面更紧凑**：全局间距温和收紧，同屏信息更多，页面观感更精致。
- **日志实时可见**：授权存储后运行日志即写入 MMAFile/Log，随时可查；暂不授权下次启动再问。
- **按压回弹动效**：按钮按下时轻微收缩再回弹，触感更柔和有趣。
- **暗色对比优化**：暗色主题下提示与状态色对比度提升，夜间阅读更清晰。
- **磨砂栏就打底**：顶栏与底栏具备半透明磨砂能力，为后续自定义主题铺路（当前默认关闭）。

## 修复

- **退出记录更完整**：修复崩溃或退出瞬间，已产生但尚未落盘的运行记录可能丢失的问题。
- **取消更加可靠**：取消构建后不再意外记为成功，历史中标记为已取消。
