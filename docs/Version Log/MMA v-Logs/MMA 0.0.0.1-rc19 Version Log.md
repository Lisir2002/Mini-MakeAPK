# MMA 0.0.0.1-rc19 Version Log

> 补齐浏览器网络能力与加载记录的可信度：明文站点不再被系统拦截成白屏；同文档路由不再冒充跳转；首帧晚到不再被误判成渲染失败。

### 修复

- **明文站点打不开**：Android 9 起系统默认拦截明文 http 页面，表现为直接白屏；现按浏览器通行做法放行，证书异常自动降级重试的路径也随之打通。
- **跳转次数虚高**：单页应用内部路由（页面内切换视图）不再被误记为网络跳转，等待时长归因更准。
- **渲染误判**：个别页面完成加载早于画面绘制，此前会被记成「未绘制」；现补记晚到的首帧，不再误报。
