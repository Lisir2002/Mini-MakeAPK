# MMA 0.0.0.1-rc12 Version Log

> 本轮聚焦稳定性与体验打磨：修复打开文件偶发崩溃、网页打不开与选中色异常，项目代码页改为真实文件目录，下拉刷新重写更顺手。

### 改进

- **真实目录树**：项目代码页改为真实文件层级，文件夹可展开折叠并显示大小。
- **下拉刷新**：项目列表下拉刷新已重写，手势更顺手且不再卡在半途不动。

### 修复

- **打开不崩溃**：修复进入文件编辑器时偶发闪退，现在可稳定打开查看与编辑。
- **网页可打开**：内置浏览器加固加载流程，多数此前打不开的网页现在能正常显示。
- **选中色正常**：修复进阶设置选中态颜色异常，现在与全局主题保持一致。
