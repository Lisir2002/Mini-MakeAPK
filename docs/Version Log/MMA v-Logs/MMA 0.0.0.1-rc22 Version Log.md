# MMA 0.0.0.1-rc22 Version Log

发布日期：2026-11-01
版本代号：渲染层探针（白屏终审观测点）

## 背景

rc21 内容度量实锤：小米登录页 DOM 有内容（107 节点 / 83 字正文），但用户看到的是白屏。
「DOM 有内容」≠「屏幕有内容」——还差最后一层裁定：WebView 表面到底画出了什么、
页面内容是不是被样式藏掉了（透明 / 隐藏 / 移出屏外 / 缩放异常）。

## 变更内容

### 新增

- **渲染层探针**：内容度量同一时点触发，三联观测一次到位：
  - `preview_render_metrics`：视图尺寸、页面缩放、文档内容高度（原生侧），
    布局视口、visualViewport 缩放、首个含文本元素的坐标与计算样式
    （opacity / visibility / display / transform / zoom / 前景背景色）（JS 侧）；
  - `preview_surface_shot`：窗口实际像素采样——近白占比与量化颜色数，
    PixelCopy 取硬件合成真值（API 26+），低版本软件快照兜底。

### 判读对照表（下一份日志使用）

| 表面近白占比 | DOM 内容 | 结论 |
|---|---|---|
| ~100% | 有 | 渲染管线把内容丢了（缩放 / transform / 合成问题） |
| 明显低于 100% | 有 | 表面有真实内容，白屏另有原因 |

元素级样式（opacity=0 / display=none / transform 出屏）任一命中即锁定页面侧隐藏机制。

## 兼容性

- 探针全部只读 + try/catch 兜底，不影响页面加载本身；仅诊断埋点变更，无行为改动。
