# MMA 0.0.0.1-rc10 Version Log

> 内置浏览器告别白屏：混合内容不再被拦截，加载失败有提示，HTML 项目可直接预览。应用图标支持上传自己的图片，进阶设置新增加载进度条可选上下位置，编辑页留白与下拉样式更精致。

### 新功能

- **加载进度条**：进阶设置新增网页加载进度条，支持开关并可选顶部或底部显示位置。

### 改进

- **图标上传**：应用图标支持从相册上传自己的图片，自动居中裁方并垫上主题色。
- **留白收敛**：编辑页各配置卡片改为随内容自适应高度，底部不再有大片空白。
- **入口一处维护**：项目代码页不再重复显示入口选择，入口文件统一在基本信息卡设置。
- **下拉更清晰**：缓存模式下拉列表加描边并提亮容器底色，选中项更好认。

### 移除

- **形状预览**：应用图标的圆形方形预览已移除，点击图标即可直接上传自定义图片。

### 修复

- **白屏修复**：内置浏览器放行混合内容并接管进度与报错，多数网站不再打开即空白。
- **代码可预览**：自己写的 HTML 项目现在能直接进入预览，不再提示仅支持网址。
- **失败有提示**：网页加载失败时显示可见提示，不再静默白屏无从判断。

### 已知问题

- **暂无已知问题**：本轮更新后未发现影响正常使用的已知问题，可放心升级体验。
