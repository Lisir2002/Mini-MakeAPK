# MMA 0.0.0.1-rc11 Version Log

> 发布日期：2026-10-29
> 版本号：`0.0.0.1-rc11`（versionCode 14）
> 标题概括：文件目录树与自研编辑器上线

> 项目代码页升级为文件目录树，点击文件进入自研编辑器 / 查看器；缓存模式换成带说明的选择卡，项目列表支持下拉刷新，网页加载基座全面优化。

### 新功能

- **文件编辑器**：项目代码页改为文件目录树，点击文件进入独立编辑器 / 查看器，支持行号与语法高亮。

- **多文件项目**：HTML 项目可新建子文件夹文件（css / js 等），网页里按相对路径直接引用即可生效。

- **下拉刷新**：项目列表支持下拉刷新，下拉即重新读取最新数据。

### 改进

- **缓存选择卡**：缓存模式改为选择卡面板，每个模式都附说明，选前就能看懂差异。

- **加载基座**：网页加载优化显示效果，暗色主题不再闪白屏，渲染进程崩溃不再整页卡死。

- **壳编辑强化**：壳条目槽位显示计数与上限提醒，地址不用写 https 也能自动补全。

- **进度条就位**：功能加载进度条开关移到进阶配置，与壳配置同屏调整。

### 已知问题

- **暂无已知问题**：本轮更新后未发现影响正常使用的已知问题，可放心升级体验。
