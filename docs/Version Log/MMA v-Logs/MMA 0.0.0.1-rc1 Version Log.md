# MMA 0.0.0.1-rc1 Version Log

MMA 首个公开发布：输入网址或 HTML 即可在设备端一键封装应用，构建历史本地加密保存；界面图标已重绘为矢量图形并支持读屏朗读，安装包更加轻量。

## 新功能

- **一键封装应用**：输入网址或 HTML 字符串，即可在设备端直接封装为可安装的应用。
- **本地即时预览**：封装前可先在应用内预览页面效果，确认无误后再生成安装包。
- **亮暗双主题**：界面自动跟随系统深浅色，基于感知均匀色板，久看舒适。
- **历史记录管理**：构建记录在本地加密保存，可随时回看、删除，数据不出设备。
- **构建过程反馈**：构建中显示进度动画，成功与失败均有明确的结果页面。

## 改进

- **图标矢量重绘**：返回、历史等界面图标改为矢量图形，任何屏幕尺寸下显示都清晰。
- **启动图标更新**：应用图标改用自适应矢量图形，新系统上呈现更精致的形状。
- **状态图标可读屏**：构建成功与失败页的状态图标补充朗读描述，视障用户可感知构建结果。
- **安装包瘦身**：安装包体积已缩减至 25MB 左右，下载与安装速度明显加快。

## 已知问题

- **暂无已知问题**：本轮更新后未发现影响正常使用的已知问题，真机验证结果将随后续版本补充。
