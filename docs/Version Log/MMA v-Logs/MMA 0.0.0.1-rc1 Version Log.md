# MMA 0.0.0.1-rc1 Version Log

本次更新将界面图标全面重绘为矢量图形，各场景显示更清晰，并支持读屏软件朗读；安装包体积缩小约三成，下载安装更快。

## 改进

- **图标矢量重绘**：返回、历史等界面图标改为矢量图形，任何屏幕尺寸下显示都清晰。
- **启动图标更新**：应用图标改用自适应矢量图形，新系统上呈现更精致的形状。
- **状态图标可读屏**：构建成功与失败页的状态图标补充朗读描述，视障用户可感知构建结果。
- **安装包瘦身**：安装包体积由约 36MB 降至约 25MB，下载与安装速度明显加快。

## 已知问题

- **暂无已知问题**：本轮更新后未发现影响正常使用的已知问题，真机验证结果将随后续版本补充。
